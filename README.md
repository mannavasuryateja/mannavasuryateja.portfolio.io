# Suryateja Mannava — Portfolio

Static site (HTML + CSS + JS). No build step. Open `index.html` in a browser.

## Replace before publishing (search in index.html)
- `RESUME_URL`  -> your résumé PDF (e.g. `assets/resume.pdf`)
- `https://github.com/` -> your GitHub profile (2 places)
- `https://linkedin.com/` -> your LinkedIn profile (2 places)
- `your.email@example.com` -> your email
- Photo: replace the `<div class="ph">...</div>` inside `.photo` with
  `<img src="assets/photo.jpg" alt="Suryateja Mannava" style="width:100%;height:100%;border-radius:25px;object-fit:cover">`

## Files
- index.html, css/style.css, js/main.js

## Deploy
Drag the folder to Netlify / Vercel / GitHub Pages.
